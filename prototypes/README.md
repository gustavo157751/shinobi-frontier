# Protótipos

## Konoha Shinobi Legends

Protótipo de RPG shinobi em JavaScript puro, isolado do monorepo principal do Shinobi Frontier para preservar a arquitetura React/TypeScript/NestJS existente.

- Código e documentação: [`konoha-shinobi-legends/`](./konoha-shinobi-legends/)
- Executar em desenvolvimento: `cd prototypes/konoha-shinobi-legends && pnpm install && pnpm dev`
- Testes: `pnpm test`
- Build estático: `pnpm build`

A integração reaproveita conceitos de formação por função/posição em implementação independente e local. Consulte `konoha-shinobi-legends/GITHUB_INTEGRATION_NOTES.md` para proveniência e escopo.
